📘 LeetCode Challenge – Core DSA Topics (Java)

### Core Data Structures & Algorithms

This repository documents my daily LeetCode challenge focused on building strong DSA fundamentals using Java.  
The problems are organized topic-wise to ensure structured learning and consistent progress.

- **Arrays** – Problems on traversal, prefix sums, sliding window, two-pointer techniques, and greedy optimization.
- **Strings** – String manipulation challenges including palindrome checks, pattern matching, frequency analysis, and edge-case handling.
- **Linked Lists** – Mastering pointer manipulation with problems on reversal, cycle detection, merging lists, and in-place operations.
- **Stack** – Stack-based problem solving such as parentheses validation, expression evaluation, and monotonic stack techniques.
- **Queue** – Understanding queue operations through circular queues, sliding window problems, and queue implementation using stacks.

Each solution includes clean code, a clear approach, and time & space complexity analysis.
